# coleandcash
Cole and Cash – POS System for TCSDI
Cole and Cash is a robust Point of Sale (POS) system built using Java Swing GUI and MySQL Workbench, designed specifically for the Training Center for Skills and Development Inc. (TCSDI). This desktop application offers an intuitive interface tailored for ease of use and operational efficiency.

The system covers essential business operations, including:

Inventory Management – Real-time stock monitoring and item tracking

Sales Processing – Seamless and accurate point-of-sale transactions

Admin Panel – Centralized control over users, roles, and reports

Employee Interface – Secure access to cashier functions and tasks

Printing Capabilities – Receipt and report generation

Interactive Dashboard – Visual overview of sales, stock levels, and user activity

Cole and Cash is crafted to simplify store operations, enhance productivity, and support business growth through a reliable and well-integrated desktop solution.
